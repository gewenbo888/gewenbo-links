# Gewenbo Links — 戈文波导航

A personal link-in-bio page collecting all of gewenbo.eth's projects in one place.

[![Live Demo](https://img.shields.io/badge/demo-gewenbo--links.vercel.app-111)](https://gewenbo-links.vercel.app)

## Overview

A bilingual (English / Chinese) landing page that links out to every project in the catalogue — AI tools, cultural explorations, games, and open-source work. A single, self-contained HTML page designed for fast loading anywhere.

## Design & Tech

- **Stack:** Single HTML file, vanilla CSS
- **Deployment:** Vercel
